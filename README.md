# Controle-de-Caminhoes-RapidoLog
Um projeto educacional para facilitar o controle de caminhões de uma transportadora.

## Tecnologias

Python 3
Programação estruturada
Listas e funções
Interface por linha de comando.

## Como rodar

1. Instale o Python 3;
2. Clone este repositório;
3. Abra o terminal na pasta do projeto;
4. Execute o comando: python Main.py;
5. Utilize o menu para cadastrar um usuário, entrar e gerenciar os caminhões

## Status

Projeto concluído.
Disciplina: Programação de Computadores do 1º Semestre de 2026.

Observação: Os dados ficam armazenados somente durante a execução. Ao fechar, os cadastros e as alterações serão perdidas.
